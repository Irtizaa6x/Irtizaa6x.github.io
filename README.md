## ✨ Features

- **Fully responsive** – works flawlessly on desktop, tablet, and mobile.
- **Collapsible sidebar** with hamburger menu on mobile devices.
- **Smooth page transitions** and automatic scroll‑to‑top on navigation.
- **Professional timeline** for activities & experience (date above each card).
- **Interactive skills section** – skills are initially faded, click to expand/collapse.
- **Live Dhaka time** displayed on the profile card.
- **Contact section** with email, GitHub, LinkedIn, and social media buttons (including WhatsApp).
- **One‑click copy** for Discord username.
- **Custom favicon** and profile picture support.

---

## 🛠️ Technologies Used

- **HTML5** – semantic structure
- **CSS3** – Flexbox, Grid, gradients, backdrop‑filter, responsive design
- **JavaScript (ES6)** – DOM manipulation, event handling, live clock, expand/collapse
- **Font Awesome 6** – icons for skills, social links, and UI elements
- **Google Fonts** – Inter & Playfair Display
